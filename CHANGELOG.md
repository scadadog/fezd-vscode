# Changelog

Notable changes to the **FEZD** editor extension (VS Code / Cursor / Windsurf).

## [Unreleased]

## [0.1.2]

### Changed

- Marketplace display name is **SCADADOG FEZD** (`FEZD` is already taken).

## [0.1.1]

### Changed

- Marketplace extension id is `scadadog-fezd`.

## [0.1.0]

### Added

- Off-prem / on-prem gateway profiles (URL in settings, API key in Secret Storage).
- **FEZD: Health** — profile, version, token scopes.
- **FEZD: Convert ZEF to STU** — `POST /api/v1/export`.
- **FEZD: Deploy (active profile)** — simulator (hosted) or PLC IP (on-prem).
- Explorer context menus on `.zef` / `.xef` / `.stu` / `.sta`.
